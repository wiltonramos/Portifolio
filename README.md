***Portfólio Profissional - Wilton Ramos***

 Sobre o Projeto
Este projeto consiste no desenvolvimento de um portfólio pessoal para apresentar meu perfil, conhecimentos, projetos e formação na área de tecnologia.

***Descrição do Portfólio***

O portfólio possui as seguintes seções:
Perfil: apresentação pessoal, área de interesse e tecnologias estudadas.
Projetos: apresentação de projetos desenvolvidos durante os estudos.
Formação: informações sobre minha formação acadêmica e trajetória na tecnologia.
Contato: links para e-mail, GitHub e LinkedIn.
Menu de navegação: permite acessar facilmente as diferentes seções do site.
Carrossel: apresenta imagens relacionadas ao portfólio.

***Tecnologias Utilizadas***

HTML5
CSS3
Bootstrap 5
GitHub
Visual Studio Code


***Novo Recurso: Seção Formação***

Foi adicionada uma nova seção chamada Formação, que apresenta informações sobre minha trajetória acadêmica e meus estudos em tecnologia.
Também foi adicionada uma opção Formação no menu de navegação, permitindo acesso direto à seção.
***Como foi implementado***
A seção foi desenvolvida utilizando HTML e componentes do Bootstrap, com uma estrutura organizada em colunas para apresentar imagem e informações de formação.
